# Cookie Evolution 🧬

Мобильная эволюционная игра в стиле Spore, созданная на React Native Expo.

## 🎮 Игровой процесс

Кликай по существу, собирай еду и эволюционируй через 4 стадии развития:

| Стадия | Описание |
|--------|----------|
| 🦠 Микроб | Начальная форма жизни. Кликай для сбора еды |
| 🐟 Существо | Появляется пассивный доход еды |
| 🦎 Животное | Ускоренный пассивный доход + новые способности |
| 🧠 Разум | Максимальная стадия — строишь цивилизацию |

## 🛠️ Технический стек

- **Expo SDK 51** + **React Native**
- **TypeScript**
- **Zustand** — управление состоянием игры
- **expo-router** — навигация
- **React Native Animated** — анимации существа
- **AsyncStorage** — сохранение прогресса

## 🚀 Запуск

```bash
npm install
npm start
```

## 📁 Структура проекта

```
/app
  index.tsx          # Главный экран игры
  _layout.tsx        # Layout с навигацией
/src
  /components
    Creature.tsx     # Компонент существа с анимацией
    StageBar.tsx     # Полоса прогресса эволюции
    ResourcePanel.tsx # Панель ресурсов
    EvolveButton.tsx  # Кнопка эволюции
  /store
    gameStore.ts     # Zustand стор (состояние игры)
  /constants
    stages.ts        # Конфигурация стадий эволюции
    colors.ts        # Цветовая палитра
  /types
    index.ts         # TypeScript типы
  /hooks
    useGameLoop.ts   # Хук игрового цикла
```
